# 깊어짐(③) 처리 내용 정리 (기획 전달용) — 2026-10-28

> 설계 근거: `docs/깊어짐_설계_v0.1.md` · CSO 검수 묶음 v0.7 시트 1-3 · 대표님 결정(2026-10-26: **신호 판별은 AI가 아니라 단어·문장 판별식**).
> 상태: **구현·배포 준비 완료(로컬 커밋, 푸시 전)**. 끄기 스위치 `SW_DEEPENING_ENABLED=0`.

## 1. 한 줄 요약
같은 고민이 나아지지 않고 **깊어지는 신호**가 쌓이면, 쏘웰라가 **전문의·상담 기관 같은 도움받을 곳을 한 번 부드럽게 안내**하고 대화는 계속합니다. **휴먼 웰니스 세션은 권하지 않습니다**(일상 고민 서비스이고, 병증이 의심되는 경우는 외부 전문 도움이 맞다는 상담사님 의견). 판단은 AI가 아니라 **정해진 단어·문장 규칙**이 합니다.

## 2. 사용자가 보게 되는 것
| 상황 | 쏘웰라의 반응 |
|---|---|
| 사용자가 "전보다 훨씬 힘들어요", "몇 달째 계속 이래요", "해 봤자 소용없어요" 같은 말을 함 | 마음을 알아준 뒤 **왜 그렇게 느끼는지·무슨 일이 있었는지를 한 가지만** 물어봄(전문기관 안내는 아직 안 함) |
| 그 답이 "요즘 야근이 많아서요" 같은 **일상 이유** | 깊어짐으로 세지 않음(일반 대화 계속) |
| 이유를 물은 뒤에도 같은 마음이 이어짐(절망 표현은 답에도 남아 있어야 함) | 깊어짐 신호로 기록 |
| 같은 고민을 **7번째 대화부터** 매번 확인해서, 신호가 **2개 이상 + 나아지는 말 없음** | 다음 답변에서 마음을 알아주고 **정신건강의학과·지역 정신건강복지센터·상담 기관**이 있다고 **제안형으로 한 번** 안내(번호 없음, 진단명 없음, 휴먼 세션 권유 없음). 대화는 그대로 이어감 |
| 안내 뒤 "조금 나아졌어요", "해 봤어요" 같은 말 | 횟수를 처음부터 다시 셈, 주의 표시 해제. 나중에 다시 쌓여 넘어가면 **다시 한 번** 안내 |
| 주의 표시가 켜진 동안 | 그 고민과 관련된 **"불편 머무르기"(조금 불편해도 머물러 보는) 실천은 추천에서 제외**. 안내는 되풀이하지 않음 |

## 3. 판별 규칙 (단어·문장 기준)
| 신호 | 기준(초안) | 비고 |
|---|---|---|
| E-1 더 힘들어졌다고 분명히 말함 | "전보다·예전보다·지난번보다·갈수록·점점·요즘 들어 더·더 심해졌·훨씬 힘들" + 힘듦 말 | "조금 → 너무"처럼 정도 단어만 바뀐 말은 세지 않음 |
| E-2 기간이 늘어남 | "몇 달째·수개월·2~9달째·몇 주째·2~9주째·반년·한 달 넘·오래전부터" + 힘듦 말 | 2주 이상은 즉시 기준이 아니라 이 신호로만 셈 |
| E-4 이유를 물은 뒤에도 절망·무가치감 | "해 봤자·소용없·어차피 안 돼·저는 원래 안 돼·뭘 해도 안…·희망이 없·쓸모없" | **이유를 묻는 답변 뒤, 그 답에도 같은 표현이 남아 있을 때만** 셈 |
| E-6 운동을 못 하면 불안이 커짐 | "운동 못 하면 불안" **+** "더 오래·시간을 늘·두 번씩" (둘 다) | 먹는 양 이야기만으로는 세지 않음(굶기가 며칠째면 섭식 안전 규칙이 따로 처리) |
| 나아짐 | "조금 나아졌·좀 나아졌·나아지고 있·한결 편해·해 봤는데 괜찮·해봤더니·해 봤어요·도움이 됐" | 하나라도 있으면 리셋 |
| 일상 이유(세지 않음) | "일 때문·야근·시험·마감·이사·감기·몸살·출장·바빠서·프로젝트·과제·논문·발표·여행·독감" | 이유를 물은 뒤의 답에 있으면 그 신호 취소 |
| 뺀 신호 | E-3(이야기 범위가 넓어짐), E-5(실천을 계속 못 함) | 상담사님 검수로 기준에서 뺌(기록만) |

> 패턴 위치: `lib/safety/deepening.ts` — 문구를 고치면 이 파일만 바꾸면 됩니다. 초안이라 **놓치는 쪽(안내를 덜 하는 쪽)으로 틀릴 수 있습니다.** 대화 로그를 보며 보강합니다.

## 4. 동작 순서
1. 사용자가 말함 → 안전 라우터가 먼저 판정(**위기·폭력은 이 규칙과 별개로 언제나 먼저**, 정해진 안내로 끝남).
2. 일반 대화로 답할 때: ① 이번 말에 깊어짐 단서가 있으면 → 답변이 "왜 그렇게 느끼는지" 한 가지를 물음. ② 넘김(주의 표시)이 난 고민이 있고 안내를 아직 안 했으면 → 도움받을 곳 안내를 한 번 넣음.
3. 답변을 보낸 **뒤**(사용자 대기 시간 0) 뒤에서: 그 말이 가리킨 **1순위 고민(뿌리)**의 대화 횟수를 세고, 직전 말에서 나온 후보를 "이유를 물었는가·일상 이유가 있는가"로 확정/취소하고, 나아짐이면 리셋. 저장은 고민(뿌리)별 상태표(`sw_user_root_state`: 누적 횟수, 나아진 뒤 횟수, 깊어짐 신호, 넘김 시각, 주의 표시).
4. 다음 대화 턴에 2의 ②가 반영됨(결과는 한 턴 뒤부터).

## 5. 안전·개인정보 원칙
- **AI가 판단하지 않음**: 신호 판별은 단어·문장 규칙. (단, "이 말이 어느 고민에 해당하는지"는 기존 해석 AI가 고른 1순위 뿌리를 그대로 씀 — 설계서 Q1 권장안.)
- **위기 이력에는 남기지 않음**(CSO ③-8): 주의 표시는 고민(뿌리) 단위, 나아짐 신호가 나오면 풀림(기간으로 풀지 않음).
- **사용자 말 조각은 저장하지 않음**: 횟수·신호 이름·시각만 저장.
- 넘김이 난 대화는 세션 안전 표시를 `elevated`로 남겨 운영 검토 대상이 됩니다(약관 예고 4항 "안전 확인이 필요하다고 표시된 대화"와 연결).
- 안내 문구는 "~할 수 없어요" 같은 거절형이 아니라 제안형이며, 진단명·휴먼 웰니스 세션 권유를 막는 문장이 들어 있습니다(테스트로 확인).

## 7. 확인한 것
- 단위 테스트 12건(신호별 포함·제외, 먼저 묻기 → 확정, 일상 이유 취소, 나아짐, 안내 문구 원칙) + 전체 439건 통과.
- 실제 서버 시험(`scripts/deepening_e2e.mjs`): 주의 표시가 켜진 고민이 있을 때 **도움받을 곳을 한 번 안내**(진단명·휴먼 세션 권유 없음), 안내했다는 표시가 남고 **되풀이되지 않음**.
- 안전 평가 35건 통과.

## 8. 알려진 한계
1. **어느 고민의 대화인지**는 AI 해석(발화 분류)이 고른 1순위 뿌리를 씁니다. 해석이 그 고민을 못 고르면 그 대화는 횟수에 안 세집니다.
2. 패턴 목록은 초안입니다. 표현이 다르면 신호를 놓칩니다(안내를 덜 하는 쪽 오류).
3. "이유를 물었는가"는 쏘웰라 답변에 "왜 그렇게·무슨 일이·어떤 일이·이유가·계기가" 같은 말이 있는지로 판단합니다(AI가 다르게 물으면 확정이 안 될 수 있음).
4. 기록 삭제 요청(숨김) 처리와의 관계는 방침 결정 후 정리합니다.

## 9. 같이 바뀐 것 (영향)
- **가설 말하기 구간이 2~4번째 → 2~3번째 답변으로 줄었습니다.** "해결책은 4번째 답변부터"(대표님 2026-10-26)와 겹쳐, 4번째 답변을 가설이 가져가면 해결책이 밀렸습니다.
- 깊어짐 처리 결과 확인용 e2e와 가설 e2e를 새 구간에 맞게 고쳤습니다.
