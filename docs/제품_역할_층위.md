# 쏘웰라 · 휴먼 웰니스 세션 · 심리상담 — 역할과 층위

대표님 확정 2026-10-23. 이 문서는 **앞으로의 개발 목적**입니다: 아래 구분이 실제 대화 흐름에서 구현되도록 만든다.

## 한 줄 정리

- **심리상담**: 목표는 **힐링(치료)**.
- **웰니스 세션**(쏘웰라·휴먼 웰니스 세션): 목표는 **자각하고, 활용해서, 발전하는 해결책 지향**.

## 예시로 보는 6개 층위

사용자 말: **"단체운동은 제 적성에 잘 안 맞는 것 같아요."**

| 층위 | 무엇을 하나 | 예 | 담당 |
|---|---|---|---|
| 1 | 겉으로 드러난 이유 | 사람들과 부대끼는 게 싫음 / 땀 많이 나는 모습을 보여주기 싫음 / 같이 하면 민폐 끼칠까 걱정 | **쏘웰라** |
| 2 | 선택한 이유에서 한 칸 아래로 | (민폐 끼치기 싫음에서) 내 컨디션이 일시적으로 안 좋음 / 달리기 같은 신체활동을 못해서 뒤처지는 게 싫음 / 외향적이지 않은데 밝은 분위기를 못 맞출까 걱정 | **쏘웰라** |
| 3 | 다시 한 칸 아래로 | (뒤처지는 게 싫음에서) 뒤처지는 자체가 싫음 / 늦게 도착한 나를 맞이하는 시선이 싫음 / 이미 힘든데 응원받는 게 싫음 / 뒤처지는 나를 데려가려는 강제성이 싫음 | **쏘웰라** |
| 4 | 그 마음이 가리키는 성향·욕구 | 약간의 완벽주의 / 주목받기 싫음 / 못하는 대로 받아들이고 싶음 / 자율성 존중 필요 | **쏘웰라** — **여기까지가 쏘웰라의 목적(분석 + 해결책 제안)** |
| 5 | 왜 그런 성향이 생겼는지, 어떻게 관리하고 싶은지, 적당히 받아들이며 극복하는 방법 모색 | | **휴먼 웰니스 세션** |
| 6 | 완벽주의·강박이 생긴 이유, 신경안정제 처방, 상담치료 | | **심리상담(의료)** |

## 개발 원칙 (이 구분을 구현한다)

1. **쏘웰라는 층위 1→4까지 한 번에 한 칸씩 내려간다.** 한 번의 질문·가설은 바로 아래 한 층만 묻는다. 사용자가 말하지 않은 층위로 건너뛰어 단정하지 않는다(제안형: "~일 수도 있을까요?").
2. **층위 4에 닿으면 해결책(실천)을 제안한다.** 분석만 하고 끝내지 않는다. 쏘웰라의 목적은 "분석 + 해결책 제안"이다. 해결책은 층위 4의 성향·욕구에 맞춘 것(예: 자율성 존중 필요 → 혼자 페이스를 정하는 운동)이어야 한다.
3. **층위 5로 가고 싶어 하면(왜 생겼는지·어떻게 관리할지) 휴먼 웰니스 세션을 안내한다.** 본인이 원할 때만, 밀어 넣지 않는다(자주·강하게 권하지 않음).
4. **층위 6(병증 의심, 원인 규명, 약·치료·진단이 필요한 이야기)은 쏘웰라도 휴먼 웰니스 세션도 아니다.** 전문 의료·상담 기관 안내로 보낸다. 상담사님 결정: 깊어짐·병증 의심에 **휴먼 세션을 권하지 않는다**(일상 고민 서비스이고, 병증이 의심되는 경우는 외부 전문 도움이 맞음).
5. 층위 4의 성향 이름("완벽주의" 등)은 **사용자 말에 근거한 가설**이다. 유형·진단으로 굳히지 않고(SAFE-003·005), 의학 용어를 쓰지 않으며, 사용자가 "맞아요/아니에요"로 고치게 한다(이미 있는 가설 확인·거절 흐름).
6. 사용자에게 보이는 소개·약관·서비스 설명에서도 같은 구분을 쓴다: 심리상담은 힐링(치료), 웰니스 세션은 자각하고 활용해 발전하는 해결책 지향. (약관 14조 "서비스의 성격"에 반영하는 문구는 법률 검토 때 함께 정한다.)

| 4 | 해석 엔진의 뿌리(root) 가설과 확인 질문(`lib/interp/*`, "이런 마음일 수도 있을까요?"), 마이페이지 "쏘웰라가 파악한 내용" |
| 해결책 | 실천 제안(`wellness_practices`, `practice_eligibility`), 오늘의 실천 |
| 5 | 휴먼 웰니스 세션 안내(상담 신청 화면) — 본인이 원할 때만 |
| 6 | 임상 경로(clinical_diagnosis/clinical_distress)의 전문 상담 권유, 위기·폭력 고정 안내, SAFE-018~021 |

개발할 때 확인할 빈틈: ① 층위 4에 닿은 뒤 해결책 제안으로 **이어지는 규칙**(지금은 가설 확인과 실천 제안이 따로 돌아감), ② 층위 5 신호("왜 이런지 알고 싶다", "어떻게 관리하나")를 알아보고 휴먼 세션을 **한 번** 안내하는 규칙, ③ 층위 6 신호에서 휴먼 세션을 권하지 않는 규칙(상담사님 결정과 일치하는지 점검).
